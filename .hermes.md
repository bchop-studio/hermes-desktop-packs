# Hermes Desktop Packs, Hermes Rules

Always load `bchop-repository-lifecycle` before any change.

- Never commit to main. Branch and PR always.
- Update the PR body after each push.
- Never commit secrets. Keep them in `.env` only.
- Run the relevant checks after every meaningful change.
- Update BUILDLOG.md at each checkpoint.
- This project only themes Hermes Desktop. It must never alter Windows OS settings, wallpaper, cursor, icons, registry, or Windows Terminal.
